(01) The system

A job feed is easy. A job feed you can trust is not.

01 / INGEST

Watch public career boards.

Sync Greenhouse, Lever, Ashby and supported public pages into one normalized job model without authenticated scraping.

02 / TRACK

Know what changed.

Track discovered, updated, missing, closed and reopened roles over time instead of treating every fetch like a fresh list.

03 / FILTER

Apply constraints before vibes.

Geography, experience, salary, paid-only rules and explicit rejection memory gate candidates before semantic similarity can influence ranking.

04 / EXPLAIN

Show the evidence.

Every recommendation carries reasons, risks and unverified metadata instead of an opaque “AI match” score.
